# Extension Icons

This directory should contain the following icon files:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon32.png` - 32x32 pixels (Windows)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Icon Requirements

- **Format**: PNG with transparency
- **Design**: Football/soccer theme with microphone or commentary elements
- **Colors**: Should work well on both light and dark backgrounds
- **Style**: Modern, clean, recognizable at small sizes

## Temporary Solution

For development, you can use any PNG files with the correct dimensions, or create simple colored squares as placeholders.

## Creating Icons

You can use tools like:
- Figma or Sketch for design
- Online icon generators
- AI tools like DALL-E or Midjourney
- Simple graphics editors like GIMP or Photoshop

The icon should represent:
- Football/soccer (⚽)
- Commentary/microphone (🎤)
- Alternative/choice concept
